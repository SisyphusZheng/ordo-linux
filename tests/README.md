# 测试

> 目标不是覆盖率，是**防回归**：每个曾经真实发生过的缺陷，都要有一条能被机器重跑的断言。

## 分层（单作者预算下只保留两层）

| 层 | 位置 | 守什么 | 跑多久 |
|---|---|---|---|
| L1 静态 | `tests/lint.sh` | 语法、shellcheck、配置解析（kdl/toml/json/ini） | 秒级 |
| L2 行为 | `tests/cases/*.sh` | 脚本在「工具缺失 / 参数错误 / 正常路径」下的行为与退出码 | 秒级 |

不做 L3（VM 内全系统验收）。理由：单作者维护不起 qemu 集群；L1+L2 已能覆盖本次评审
发现的全部 5 个 P0 与大部分 P1。

## 约定

- 每个用例是独立可执行脚本，退出 0 = 通过。
- 用例不得依赖 ZFS/niri/Gentoo —— 它们要能在开发机（macOS）上跑。
- 需要「假装装了某工具」时，用 `tests/lib/fakebin` 造 PATH。
- 新增一个 P0/P1 修复时，**同一个 commit 必须带一条对应用例**。

# ADR 0004 — 智能体运行环境

- 状态：已采纳（决策）；实现待 L2
- 日期：2026-11-18
- 关联：ADR 0007（沙箱）

## 一、问题

若系统需要为智能体提供运行环境，需确定两件事：调用接口与权限约束。

本 ADR 记录决策，不包含实现。文中出现的 `ordo agent` 等命令尚未实现。

## 二、沙箱：bubblewrap

不使用裸 Landlock。理由：

1. Landlock 无命令行工具，内核只提供 syscall，直接使用需自行编写 C 包装
2. Landlock 不隔离视野：不建 namespace，进程仍可读取 `/proc`、观察其它进程
3. Landlock 无资源限制，CPU 与内存需 cgroups
4. Landlock 网络仅能限制端口，不能限制地址
5. Landlock ABI 分版本（v1 文件 / v4 TCP / v6 信号 / v10 UDP），不可逆
6. Landlock 错误信息仅报 EACCES，不区分拒绝来源

bubblewrap 内部已使用 Landlock、namespace 与 seccomp，提供声明式命令行，
并在 Flatpak 中长期使用。

L1 系统实测：

```
CONFIG_SECURITY_LANDLOCK=y
LSM 列表: landlock,yama,bpf
bubblewrap 已安装（/usr/bin/bwrap）
```

## 三、接口原则

不提供接口优于提供受限接口。不提供的接口本身即边界，无需依赖策略正确。

接口为固定数量的窄命令，不提供通用 shell 执行。
具体命令集在实现阶段确定。

## 四、权限模型

采用默认拒绝，按能力授予最小权限。三档：

| 档位 | 范围 |
|---|---|
| workspace | 仅工作目录读写 |
| standard | 增加网络与包管理只读 |
| trusted | 接近全权限，限制危险路径，需用户显式授权 |

默认档为 workspace。提升档位需用户显式操作。

## 五、回滚与重启

快照为树形结构，每次智能体操作产生一个快照。

ZFS 的行为约束：

| 操作 | 在线可行 |
|---|---|
| 创建快照 | 是 |
| 回滚到最新快照（无子快照） | 是 |
| 回滚到祖先快照 | 否，需重启经 ZFSBootMenu |

回滚到祖先快照需重启，因此智能体触发重启须经批准：

- 交互会话：终端确认
- 无人值守：需预先授予完全权限，授权有时效、记审计日志、不跨会话继承

## 六、审计模式

先观察后收紧：先以 audit 模式记录操作的意图，积累数据后再生成策略，
最后切换至 enforce。

当前无真实使用数据，直接制定策略必然偏离实际。故审计模式与实现同期，
不提前。

# ADR 0010 — 会话总线、输入法环境与虚拟机显示

- 状态：已采纳（实机验证）
- 日期：2026-11-21
- 关联：ADR 0009（桌面栈终审）、deviations #40/#54

## 一、问题

niri 会话里三个组件反复"表面正常、实际失效"：

1. **D-Bus 会话总线**：`/run/user/$UID/bus` 不存在，每个会话靠
   `dbus-run-session` 自建 `/tmp/dbus-XXXX` 临时总线。后果是外部工具
   （Warehouse、脚本、Flatpak 服务激活）连不上会话总线，
   Warehouse 显示 "No Packages Found"，portal 静默降级。
2. **中文输入**：GTK 应用打不出中文，且没有报错。
3. **虚拟机黑屏**：niri 报 `no allocator available`。

## 二、根因与决策

### 2.1 Gentoo 的 dbus 有两套独立服务

| 类型 | 服务文件 | 总线地址 |
|---|---|---|
| 系统总线 | `/etc/init.d/dbus`（`--system`） | `/run/dbus/system_bus_socket` |
| **用户会话总线** | `/etc/user/init.d/dbus` | `/run/user/$UID/bus` |

只启用系统总线（`/etc/runlevels/default/dbus`）时，用户会话总线从未启动。
**决策**：`install.sh` 建 `/etc/user/runlevels/default/dbus` 软链，并把
`dbus-update-activation-environment` 写进会话包装脚本，让被 D-Bus 拉起的
服务继承 `WAYLAND_DISPLAY` / `XDG_RUNTIME_DIR`。

验收判据：`[ -S /run/user/$(id -u)/bus ]` 为真，且 `flatpak` 服务可激活。

### 2.2 输入法变量：`GTK_IM_MODULE=wayland`

niri（Smithay）实现了 `zwp_text_input_manager_v3` 与
`zwp_input_popup_surface_v2`（二进制实证：`strings` 可见协议符号）。

- GTK 应用设 `wayland` → 走 text-input-v3 协议，fcitx5 作为合成器的
  输入法前端工作。是 实测可用（拼音预编辑 + rime 候选框）
- 设 `fcitx` → 走 GTK immodule，绕过合成器自己找输入法，纯 Wayland 会话下失败。

**决策**：`GTK_IM_MODULE=wayland`、`QT_IM_MODULE=fcitx`、
`XMODIFIERS=@im=fcitx` 三者同时设（X11 应用经 xwayland-satellite
拿不到 v3 协议，只能靠 `XMODIFIERS`）。定义在 `/etc/env.d/99imm`，
由 `env-update` 编译进 `/etc/profile.env`。

### 2.3 虚拟机显示必须带 GL

| UTM 显示硬件 | dmesg 能力 | 结果 |
|---|---|---|
| `virtio-ramfb` | `-virgl -resource_blob -host_visible`，`cap sets: 0` | niri 黑屏 |
| **`virtio-ramfb-gl`** | `+virgl +resource_blob +host_visible`，`cap sets: 4` | 正常渲染 |

**决策**：VM 验收要求使用 `virtio-ramfb-gl`（或 `virtio-gpu-pci` 带 virgl）。
这是环境要求，不是系统缺陷 —— 记录在此避免重复排查。

## 三、niri 配置要点（实测，非文档推断）

- `window-rule` 只有 `match app-id=` / `match title=`，**没有 `is-dialog` 匹配器**（26.04 实况）
- KDL 注释只能用 `//`；中文后接 `#` 会被当成 token
- `spawn-at-startup` 是 **execvp 语义，不经过 shell**：`$HOME` 不展开，
  不能写复合命令。需要条件的场景必须包一层独立脚本
- 鼠标拖动：`Mod+左键` 拖窗口，**拖动中右键**切换悬浮/平铺（内置行为）

## 四、编译要点

- `USE="-screencast"` 可完全省掉 clang 全家桶（screencast 才需要 BDEPEND clang）
- GURU 的 `gui-wm/niri` 最初只有 `~amd64`，arm64 需 `package.accept_keywords`
